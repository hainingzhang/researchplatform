# 网络研究共享文件平台

Research Platform 面向研究团队提供文献资料、研究方案等文件的网络共享访问方式。成员通过 SSH 隧道连接服务器上的 Samba 共享；SSH 密钥负责建立受限隧道，Samba 账号负责实际的文件访问权限。

## 工作方式

```text
成员电脑 ── SSH 隧道 ──▶ 云主机 tunnel 账号 ──▶ 127.0.0.1:445（Samba）
```

- **SSH 隧道**：成员各自使用独立密钥，通过共用的受限 `tunnel` 账号转发到服务器本机的 Samba 服务。
- **文件访问**：每位成员使用独立 Samba 账号和密码，具体共享目录的读写权限由服务器端配置控制。
- **客户端**：Mac 通过脚本挂载共享目录；Windows 通过脚本映射网络盘。

## 成员使用流程

1. 向管理员获取对应操作系统的配置程序，以及个人 Samba 用户名和密码。
2. 按《成员使用指南》运行一次配置程序，生成 SSH 密钥并创建连接/断开脚本。
3. 将程序显示的**公钥**发给管理员，等待授权确认。
4. 授权后使用桌面上的连接脚本访问共享文件，完成后运行断开脚本。

Mac 共享目录默认位于 `~/mnt/research`；Windows 默认映射为 `Z:`。Windows 客户端需使用 Windows 11 24H2 或更新版本。

## 管理员部署概要

1. 按管理员指南配置服务器上的受限 SSH `tunnel` 账号、Samba 服务和共享权限。
2. 在分发脚本顶部填写服务器地址、共享名等参数，并分别打包 Mac 和 Windows 客户端配置程序。
3. 将对应分发包和成员指南发给成员；Samba 凭据应通过安全渠道单独提供。
4. 核验收到的公钥，将带有转发限制的公钥加入 `authorized_keys`，再通知成员已授权。
5. 发放前先按管理员指南完成 Mac、Windows 连接和权限限制验证。

## 安全注意事项

- **私钥只保存在成员自己的设备上**，不得发送或上传；管理员只需要公钥。
- 每位成员使用独立 SSH 密钥和 Samba 账号，离组时应撤销对应公钥并禁用或删除 Samba 账号。
- Samba 密码不要与客户端分发包放在同一条消息中。
- 文件通过网络文件系统访问，大文件可能有延迟；多人同时编辑同一文件时应避免冲突。
